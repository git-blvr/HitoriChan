Overview

The Overview page is the landing screen after you pick a server from the top-left dropdown. It gives you a quick snapshot of the bot's health and server activity.

Stats cards

CardWhat it shows
ServersNumber of Discord servers the bot is in.
UsersTotal members across all servers the bot can see.
Total MessagesTotal messages logged by the bot.
Voice HoursTotal hours spent in voice channels.
CollaboratorsNumber of dashboard accounts that exist.
UptimeHow long the bot has been running since the last restart.

Server Activity chart

The chart shows message activity over the last 7, 30 or 90 days. Use the Range dropdown to change the window.

System Status

Shows the bot status (online/offline), Node.js version, platform, memory usage and CPU count.

Tip Click the refresh icon in the top right of any section to reload its data.

Economy

The economy system lets you set up one or two currencies that users earn through chatting, streaks, dailies and shop sales.

Primary & Secondary Currency

  • Name — the display name of the currency, e.g. "Starry Coins".
  • Symbol — a short symbol, e.g. "SC".
  • Emoji — an emoji shown next to balances. Click the input to open the emoji picker or type your own.

Daily Reward

Sets the min/max range users can receive when they run the daily command. A random amount between min and max is given.

Server Richboard

The table shows the top users by primary and secondary balance, with avatars and display names.

AI Config

The AI module lets the bot reply to messages using Groq. You can make it respond everywhere or only in one channel.

  • Enabled — turn the AI on/off.
  • Mode — Everywhere replies to mentions and direct replies; Specific channel only talks in the chosen channel.
  • Channel — the channel the AI watches when in "Specific channel" mode.
  • Custom Prompt — system instructions for the AI's personality. Use the Import payload button to extract text from a Discord message or embed JSON.

Streak

Streaks reward users for sending messages consistently. Every day a user sends a message in the tracked channel, their streak grows.

  • Enabled — turn the streak tracker on/off.
  • Track Channel — the channel that counts towards streaks. Leave empty to track all channels.
  • Notify Channel — the channel where streak up/lost notifications are sent. Leave empty to use the tracked channel.

Moderation

Global moderation settings used by warn, mute, kick, ban and timeout commands.

  • Log Channel — where moderation cases and logs are posted.
  • Mod Role — the role that can use moderation commands (besides server admins).

Command Prefix

The character that starts prefix commands, e.g. ! or ~. Slash commands do not use this prefix.

Cases

Lists all moderation cases for the selected server. Each case shows the action, target user, moderator, reason and date. User IDs are resolved into avatars + display names automatically.

Tickets

Ticket panels are the messages users click to open a ticket. You can build them as a normal Discord embed or as a Components V2 (CV2) message.

Panel basics

  • Name — internal name for the panel.
  • Type — Embed or CV2.
  • Button Label / Color — the button users press to open a ticket.
  • Title / Description — panel text. The Import payload button lets you paste a Discord message and extract the title or description.
  • Color / Dominant color — accent color of the panel. Click Dominant color to sample the last image URL.
  • Image / Thumbnail URL — optional media shown on the panel.

Embed fields

Add, reorder or import fields for the embed version. Use Payload to paste a full embed JSON.

CV2 Components

Build a Components V2 message with text, images, separators and ticket buttons. You can also import an existing CV2 payload.

Categories

When a user opens a ticket they can pick a category from a dropdown. Add categories with a label and optional description.

Other settings

  • Ticket Category — channel category new ticket channels are created under.
  • Staff Role — role that can claim/close tickets.
  • Transcript Channel — where a close summary is posted.
  • Welcome Message — message sent inside the new ticket channel. {user} pings the author.
  • Send Panel To — channel to post the finished panel in.

Shop

The shop lets users buy roles, multipliers and unlocked commands with economy currency.

Shop Settings

  • Shop interface enabled — show the shop CV2 interface.
  • Shop Channel — the channel where /shop posts the interface.
  • Accent Color / Dominant color — styling for the shop CV2 message.

Shop Interface Builder

Build the shop's CV2 message with text, images, media galleries and separators. Use Import from Payload to load an existing CV2 JSON.

Categories

Items are grouped into categories. Each category has a name, description and sort order.

Items

Items can have a price, optional role reward, earnings/level multiplier, required role, limited stock and a max per user. You can also list commands the item unlocks.

Boost

Booster perks run when someone boosts the server.

  • Enabled — turn booster rewards on/off.
  • Primary / Secondary Reward — economy given on boost.
  • Booster Role — role assigned to boosters (also removed when boost ends).
  • Earnings Multiplier / Level Bonus — passive boost to the user's economy multiplier and level.
  • Unlocks Commands — one command name per line that boosters can use.
  • Thank-you Channel / Message — channel and message sent when someone boosts. {user} pings the booster.

Triggers

Keyword triggers run a command when a user types a keyword in chat. Use the searchable command picker to pick which command fires.

  • Keyword — the word that triggers the command.
  • Command — slash or prefix command to run. Type to filter the list.

Logs

The Logs section shows two tables:

  • Command Logs — every command used, with user, command, source (slash/prefix) and success/failure. Filter by user, command or success status.
  • Message Logs — messages the bot has logged. Filter by user or content. User and channel IDs are resolved into names.

Tip The user filters are searchable dropdowns loaded from the server's member list.

Quests

Quests are custom objectives built with dropdowns. When a user's actions match the conditions, the quest completes and runs all tasks you add.

Schedule

  • Once — one completion per user, ever.
  • Daily — resets every day so users can complete it again.
  • Weekly — resets every week.

Condition builder

Each quest has one or more condition blocks. You can set the whole quest to require All (AND) or Any (OR) of them.

Each block has:

  • NOT — invert the condition.
  • Entity — what you are checking (Message, Messages, User, Voice, Commands, Reactions, Invites, Economy, Channel, Guild).
  • Field — the specific thing to check (e.g. Content, Channel, Has role).
  • Operator — how to compare (INCLUDE, =, >=, etc.).
  • Value — the number, text, channel, role or user to check against. Text inputs can use $variable to reference a variable.

Reward

Besides tasks, a quest can have a direct reward. Choose Currency (value = primary or secondary) or Role (value = role ID), and an amount.

Dashboard Users

Create and manage accounts for people who can log into this dashboard. The default Admin account always exists and has all permissions.

  • Username — login name.
  • Password — required when creating a user; leave empty when editing to keep the current password.
  • Permissions — sections the user can access. Uncheck everything to give read-only access to overview.

All dashboard passwords are hashed with scrypt. Failed login attempts are limited to 3 per IP, with a 15 minute lockout.

Tips & Shortcuts

  • Guild selector — most sections need a server selected to load data. The bot must be in that server.
  • Searchable dropdowns — long channel, role and member lists have a filter input. Type to narrow options.
  • Import payload — many text inputs and textareas have an Import payload button. Paste a Discord message, embed or CV2 JSON and the text is extracted.
  • Dominant color — ticket and shop builders can sample the dominant color from an image URL.
  • Refresh — the circular arrow in the top bar re-runs the current section's loader.
  • Mobile — the dashboard is responsive. On small screens the sidebar becomes a horizontal nav.
